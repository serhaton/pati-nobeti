App description / audience / value:
Pati Uzat is a community app for organizing stray-animal care. It helps volunteers and community admins manage feeding points, animal records, expenses (food/veterinary), contribution records, member approvals, and shared budget visibility (debt/credit tracking). Target users are animal volunteers and neighborhood/community rescue groups. The app improves coordination and transparency by keeping operational records and approvals in one place.

Important clarification:
This is not a financial services app. It does not process payments, move money, or connect to banks, cards, wallets, or payment gateways. Expense/contribution entries are informational tracking records only.

Reviewer access instructions:
No special reviewer account is required. Reviewer can register via email, sign in with email/password, then create or join a community. Core features become active after a community is selected. Admin-only actions include member approval/rejection, feeding point management, expense approval, and contribution allocation. If membership is pending approval, some admin-controlled actions are intentionally restricted. No sample files are needed.

Core external services and SDKs:
- Supabase: authentication, database, row-level access control, storage, edge functions
- Expo Notifications: push token handling/integration
- Expo Location + React Native Maps: map/location-based feeding point features
- Google Mobile Ads (AdMob): banner ads

Regional differences:
No region-specific feature gates. Behavior is consistent across regions; only map/geolocation/network conditions may vary.

Regulated content / protected material:
The app is not in a regulated service category (medical, legal, gambling, financial advisory, etc.). No bundled protected third-party media. Uploaded photos/receipts are user-provided.

Analytics:
No dedicated third-party product analytics SDK in this build.

Data sharing / storage:
Data is shared with Supabase for backend operations and with AdMob for ad serving. Backend data is stored in Supabase infrastructure configured by the app owner; ad-related processing follows Google policies.

User/device data collected for app functionality:
Account data (email/auth provider; optional profile fields such as name/phone), community/membership data, feeding point coordinates/logs, expense/contribution records, uploaded photos/receipts, and push notification device tokens. Location is permission-based and used only for map features.
